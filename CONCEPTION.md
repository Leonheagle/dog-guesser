# Conception de Dog-guesser

Dans ce fichier markdown j'expliquer comment j'ai conceptualisé le jeu et comment j'ai utilisé l'IA à ce but

## Choix de conception

Le jeu est réalisé en trois grandes parties : la partie python, la partie client et la partie server.
Au début de ma conception, mon server effectuait tous éléments logique en back alors que mon client ne faisait qu'une communication avec le server afin de recevoir les informations.
Dans ma version finale le server est principalement utilisé pour communiquer avec le client et enregistrer les scores des joueurs.
J'utilise tkinter avec mon client pour la réalisation de la page du jeu.

## Utilisation de l'intelligence artificielle

J'ai utilisé une intelligence artificielle conversationnelle comme outil d'accompagnement pendant le développement. Mon objectif n'était pas uniquement d'obtenir du code fonctionnel, mais aussi de comprendre les mécanismes utilisés et les choix possibles.

Le travail s'est déroulé de manière progressive :

- Compréhension du code : demande d'explications sur les fonctions Python, les imports, les échanges réseau et les mécanismes de gestion des réponses.

- Conception de l'application : réflexion sur la séparation entre le client, le serveur et les fonctions de récupération des données.

- Résolution des problèmes : analyse des erreurs rencontrées et recherche de corrections adaptées au fonctionnement du projet.

- Amélioration progressive : ajustement de l'interface, de la gestion des scores, du redémarrage des parties et de l'organisation des fichiers.

J'ai privilégié une approche itérative : je soumettais une question ou un problème précis, j'examinais les explications et les propositions, puis je les confrontais au fonctionnement de mon application. Cette méthode m'a permis de progresser par étapes plutôt que de construire l'ensemble du projet en une seule fois. L'IA m'a ici surtout permis l'écriture et la liaison du code avec tkinter.

L'IA a donc servi d'assistant technique et pédagogique. Les choix de conception ont été discutés au fil du développement, en tenant compte des objectifs du projet et de mon niveau de compréhension.
